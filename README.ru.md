# AppTimer

[English README](README.md)

**AppTimer** — локальное приложение macOS для ручного учёта времени по одному или нескольким проектам. Оно живёт в Menu Bar, не требует аккаунта и не отправляет данные в сеть.

> Проект никогда не выбирается автоматически. Учёт начинается только после явного выбора хотя бы одного проекта.

## Установка

Для Apple Silicon скачайте актуальный установщик на странице [GitHub Releases](https://github.com/artyomliske/AppTimer/releases). Откройте DMG и перетащите `AppTimer` на ярлык `Applications`.

Если вы собираете приложение самостоятельно, используйте:

```bash
make install
```

Эта команда собирает AppTimer на вашем Mac и копирует его в `/Applications`; для такой локальной сборки атрибут карантина не появляется.

## Возможности

| Возможность | Что делает |
|---|---|
| Мультипроектный учёт | Позволяет выбрать один или несколько проектов и распределить время поровну, полностью каждому или по ручным долям. |
| Calm Focus | Focus Pulse, фокус-блоки на 25 / 50 / 90 минут, кольцо концентрации и недельный ритм. |
| Focus Companion | Локальные роли рабочих, нейтральных и отвлекающих приложений с мягкими напоминаниями. |
| Отчёты | Сводки по проектам и программам, CSV с реквизитами клиента и расчётом суммы. |
| Надёжность учёта | Heartbeat активной сессии и восстановление после аварийного завершения без добавления лишнего времени. |

## Приватность

Данные остаются только на Mac. AppTimer сохраняет даты, длительности, названия проектов, имя активной программы и её bundle identifier. Он не использует облако, аккаунты, телеметрию, содержимое окон, URL-адреса, нажатия клавиш, буфер обмена или запись экрана.

## Разработка

Требуются macOS 14+ и Xcode со SwiftData. Общие команды:

```bash
make test    # XCTest
make build   # Release-сборка
make dmg     # установочный DMG с ярлыком Applications
```
