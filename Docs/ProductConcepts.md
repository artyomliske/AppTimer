# Следующие продуктовые концепты AppTimer

## Принцип отбора

Каждый концепт должен усиливать осознанную работу, не создавать облачную зависимость и не назначать проекты автоматически. AppTimer остаётся локальным инструментом, в котором пользователь принимает решения, а приложение делает их нагляднее и легче для повторения.

| Концепт | Пользовательская ценность | Локальная граница | Сложность |
|---|---|---|---|
| **Focus Compass** | Помогает начать фокус с намерением, удержать один выбранный проект и завершить коротким итогом. | Намерение и итог сохраняются только на Mac и всегда привязаны к вручную выбранному проекту. | Средняя |
| **Project Momentum** | Показывает темп недели: выполнено, осталось до локальной цели, где время реально распределяется. | Использует только существующие интервалы, цели проекта и локальные расчёты. | Низкая |
| **Close the Day** | Превращает отчёт в спокойный вечерний ритуал: что сделано, что отвлекало, что продолжить завтра. | Никаких отправок и генеративной оценки; выводятся лишь фактически сохранённые данные. | Средняя |
| **Timeline Lens** | Позволяет вручную отфильтровать Timeline по проекту, роли приложения или периоду, чтобы видеть паттерны дня. | Работает с уже opt-in сохранёнными `ContextSegment` и ручными сессиями. | Средняя |

## Рекомендуемое направление: Calm Momentum

Рекомендуемый следующий релиз объединяет **Focus Compass**, **Project Momentum** и **Close the Day** в один понятный цикл: пользователь выбирает проект и задаёт короткое намерение, видит движение к своей цели в течение недели, а в конце дня получает локальную сводку, которую может отредактировать или пропустить.

### 1. Focus Compass

Перед запуском 25/50/90-минутного блока появляется компактная карточка «На чём я работаю?». Пользователь вручную выбирает уже активный проект и пишет необязательное однофразовое намерение. Во время блока намерение остаётся видимым рядом с Focus Pulse. После завершения пользователь может отметить результат как «сделано», «продолжу позже» или пропустить отметку. Этот механизм не интерпретирует содержимое приложений и не запускает учёт сам.

### 2. Project Momentum

На экране «Сегодня» появляется секция «Темп недели»: три наиболее релевантных проекта с локальной недельной целью, фактическим временем и визуальным прогрессом. Карточка не ранжирует проекты скрытым алгоритмом: она показывает только те проекты, которые пользователь выбрал вручную или которые имеют установленную цель. Один клик открывает соответствующий проект или запускает новый focus-блок только после явного выбора проекта.

### 3. Close the Day

После завершения последнего учёта дня или по ручному открытию появляется необязательная карточка завершения дня. Она объединяет фактическое время, распределение по проектам, рабочий/нейтральный/отвлекающий контекст и незавершённые focus-блоки. Пользователь может добавить короткую заметку «продолжить завтра»; никакая рекомендация не отправляется за пределы Mac.

## Предлагаемая последовательность

Сначала реализовать `Project Momentum`, потому что он использует уже существующие данные и сразу делает Dashboard полезнее. Затем добавить `Focus Compass` с компактным локальным состоянием намерения. Наконец, встроить `Close the Day` как ручной ритуал, а `Timeline Lens` оставить следующим отдельным обновлением, чтобы не перегружать первый релиз новой логикой фильтрации.
