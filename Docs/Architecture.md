# Архитектура AppTimer 1.0

## Назначение

AppTimer — локальный трекер времени для macOS. Пользователь вручную выбирает один или несколько проектов, а приложение фиксирует интервалы работы и контекст активных программ. Смена программы **не меняет** назначенный проект: она нужна только для аналитики в отчёте.

## Данные

| Сущность | Ключевые поля | Роль |
|---|---|---|
| `Project` | `id`, `name`, `colorHex`, `isArchived` | Пользовательский проект. |
| `WorkSession` | `startedAt`, `endedAt`, `allocationMode` | Непрерывный интервал с неизменяемой конфигурацией распределения. |
| `SessionProjectAllocation` | `project`, `weight` | Доля конкретного проекта в интервале. |
| `AppSegment` | `bundleIdentifier`, `appName`, `startedAt`, `endedAt` | Метка активного приложения внутри интервала. |

Каждый интервал хранит отдельные `SessionProjectAllocation`. Из-за этого исторические отчёты не меняются, если пользователь позже переименует проект, изменит режим по умолчанию или начнёт новую сессию с другим набором проектов.

## Правила жизненного цикла

| Событие | Поведение |
|---|---|
| Нет выбранных проектов | Учёт не запускается. |
| Нажатие «Начать учёт» | Создаётся `WorkSession` с текущими проектами, режимом и весами. |
| Смена проектов | Открытый интервал закрывается; при наличии проектов создаётся новый. |
| Смена режима или долей | Открытый интервал закрывается и перезапускается с новой конфигурацией. |
| Смена активной программы | Предыдущий `AppSegment` закрывается, создаётся новый. |
| Сон Mac или выход из активной сессии | Интервал и текущий сегмент закрываются; сон не учитывается. |
| Активное приложение — AppTimer | Проектный интервал продолжается, но сегмент приложения не создаётся. |

## Распределение времени

Движок `AllocationEngine` создаёт веса в момент старта `WorkSession`.

| Режим | Формула веса проекта |
|---|---|
| `equal` | `1 / число выбранных проектов` |
| `fullToEach` | `1` для каждого выбранного проекта |
| `customWeights` | Введённый вес, нормализованный к сумме `1` |

Отчёт всегда сначала вычисляет пересечение интервала с выбранным периодом, а затем умножает длительность на сохранённый вес. Поэтому при режиме `fullToEach` распределённая сумма намеренно может быть выше фактической длительности.

## Интерфейс

Menu Bar — основной способ взаимодействия: выбор проектов, добавление проекта, выбор режима и запуск либо остановка учёта. Dashboard открывается отдельным `NSPanel`, поэтому у приложения нет иконки в Dock. Dashboard содержит четыре раздела: **Сегодня**, **Проекты**, **Отчёты** и **Настройки**.

## Конфиденциальность

Для получения контекста программ AppTimer использует `NSWorkspace` и системные уведомления об активации приложений. В первой версии не применяются Accessibility API, захват экрана, чтение окон или сетевые сервисы. Данные сохраняются в локальном контейнере SwiftData.
