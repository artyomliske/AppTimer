# Визуальная система AppTimer

## Источник истины

Начиная с переработки после 2.0.1, источник истины для AppTimer — выбранный пользователем GitHub-концепт: светлый нативный macOS-интерфейс с графичной фокус-метрикой, насыщенным синим акцентом, карточками проектов и компактным, но заметным Menu Bar-пульсом.

## Принципы

| Принцип | Нативная реализация SwiftUI |
|---|---|
| Фокус виден сразу | Экран «Сегодня» начинаетcя с большой кольцевой метрики и краткого результата дня. |
| Работа читается как композиция | Выбранные проекты показаны как цветные карточки с временем, долей и progress bar, а не только как строки. |
| Спокойная структурность | Используются системные материалы, `RoundedRectangle` 16–20 pt, тонкие границы и тени вместо кастомного рендеринга окна. |
| Один цвет действия | `AppTimerBlue` используется для focus ring, активной навигации, primary CTA и прогресса. Красный сохраняется только для остановки учёта, оранжевый — для отвлечений. |
| Нативность важнее имитации | Сохраняются системные sidebar, кнопки, доступность, Dynamic Type и контраст macOS; концепт переводится в SwiftUI, а не переносится как изображение. |

## Карта интерфейса

| Контекст | Основной акцент |
|---|---|
| Menu Bar | Focus Pulse, крупное время, цветные чипы выбранных проектов, единый CTA учёта. |
| Сегодня | Кольцо фокуса, итог дня, карточки проектов, локальная сводка приложений и недельный ритм. |
| Таймлайн | Светлая хронологическая дорожка с синими ручными сессиями и приглушённым контекстом приложений. |
| Проекты | Карточки с цветовым идентификатором, статусом и быстрыми действиями. |
| Отчёты | Сегмент периода, ранжированные проектные карточки и ясные числовые итоги. |
| Настройки | Секционные поверхности с короткими объяснениями приватности и локального хранения. |

## Ограничения

Переработка не изменяет модель локальных данных, правила распределения времени, opt-in условия Timeline, существующие горячие клавиши или доступность функций. Любая визуальная метрика выводится только из фактически сохранённых в приложении данных.
