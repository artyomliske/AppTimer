# AppTimer 1.1 — план расширения

Версия 1.1 сохраняет основной принцип AppTimer: учёт запускается пользователем вручную, а все данные остаются на Mac. Новые возможности разделены на настройки приложения, корректировку завершённых интервалов и представление отчётных данных.

| Блок | Решение |
|---|---|
| Автозапуск | `SMAppService.mainApp` с явным переключателем в настройках. |
| Горячая клавиша | Глобальная комбинация `⌥⌘T` запускает либо останавливает учёт; её можно отключить в настройках. |
| Исключённые программы | Набор bundle identifier в `UserDefaults`; сегменты остаются в локальной базе, но не попадают в отчёты. |
| Корректировка | Пользователь может менять начало и конец завершённой сессии или удалить её. Активный интервал не редактируется. |
| CSV | Отчёт экспортируется через `NSSavePanel` в UTF-8 CSV с колонками периода, проекта, фактического и распределённого времени. |
| Неделя | Для каждого дня строится локальная сводка с длительностью и проектами; отчёт не требует дополнительной агрегирующей таблицы. |

При исключении программы AppTimer не перестаёт учитывать выбранный проект: из отчёта программ скрываются только сегменты исключённых приложений. Это не меняет фактическую или распределённую длительность проектных интервалов.
