# AppTimer Calm Focus — визуальная система

## Цель

Calm Focus превращает AppTimer из набора таблиц в спокойный персональный инструмент возвращения к задаче. Интерфейс должен отвечать на три вопроса одним взглядом: «я сейчас в фокусе?», «сколько времени осталось?» и «каким был мой ритм на неделе?». Он не использует соревновательные рейтинги, тревожные алерты или агрессивные красные состояния вне реального отвлечения.

## Визуальные роли

| Состояние | Акцент | Значение |
|---|---|---|
| Покой | Slate / secondary | Учёт не идёт или фокус-сессия не выбрана. |
| Учёт | Насыщенный сине-голубой | Активный проект и обычный учёт времени. |
| Фокус-сессия | Холодный индиго-циан | Идёт осознанный блок 25, 50 или 90 минут. |
| Отвлечение | Янтарный | Активно помеченное отвлекающее приложение. |
| Завершение | Мягкий зелёный | Фокус-сессия завершена. |

Цвет остаётся дополнительным сигналом: состояние всегда дублируется подписью и SF Symbol. Это сохраняет читаемость для пользователей с разным восприятием цвета.

## Focus Pulse

Menu Bar получает компактный Focus Pulse: круг с цветным ядром и краткой подписью состояния. В покое он нейтрален; во время активного учёта становится синим; во время фокус-сессии получает второе кольцо прогресса; при отвлечении становится янтарным. Анимация применяется только к изменению прозрачности и масштаба с учётом Reduce Motion.

## Фокус-сессии

Фокус-сессия — дополнительный намеренный таймер поверх ручного учёта проекта. Пользователь выбирает 25, 50 или 90 минут. Если учёт не запущен, AppTimer запускает его только при наличии выбранного проекта; если проект не выбран, кнопка остаётся недоступной. По завершении AppTimer оставляет учёт под контролем пользователя, завершает только фокус-сессию и показывает локальное уведомление о подходящем моменте для паузы.

| Длительность | Сценарий | Рекомендация |
|---:|---|---|
| 25 минут | Разогрев, короткая задача, начало дня | Одна краткая задача без переключений. |
| 50 минут | Обычный глубокий блок | Отключить лишние каналы коммуникации. |
| 90 минут | Длинная творческая или инженерная работа | Запланировать перерыв после уведомления. |

## Экран «Сегодня»

Верхняя часть экрана получает круг концентрации. Его сегменты показывают контекст сохранённых активных приложений: рабочий, отвлекающий и нейтральный. Рядом отображаются время работы и состояние текущего блока. Ниже размещается недельная тепловая карта из семи ячеек, где более насыщенный цвет означает больше рабочего контекста. Интенсивность не сравнивает пользователя с другими и не трактуется как оценка качества.

## Принципы приватности

Calm Focus использует только уже существующие локальные сегменты активных приложений: bundle identifier, отображаемое имя, время начала и окончания. Он не создаёт новых разрешений для чтения экрана, действий клавиатуры, содержимого окна, сайтов или сообщений. Фокус-сессии и визуальные сводки также остаются локальными.
