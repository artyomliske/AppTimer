# Локализация AppTimer

AppTimer использует локаль macOS и не хранит выбранный язык в пользовательских данных. Русский язык остаётся языком разработки, а английский вариант включён в bundle приложения как `Localizable.strings`.

| Область | Поведение |
|---|---|
| Menu Bar и Dashboard | Статические SwiftUI-строки берутся из русской или английской таблицы ресурсов. |
| Статусы и уведомления | Динамические сообщения AppTimerStore формируются через `L10n`, включая подстановку названия проекта, длительности и приложения. |
| Доменная логика | Названия режимов распределения, ролей приложений, Focus Pulse и формат длительности зависят от текущей локали. |
| CSV | Заголовок экспортируемой таблицы соответствует языку интерфейса. |
| Локальные данные | Язык не изменяет SwiftData-модели, идентификаторы приложений, историю интервалов или настройки Focus Companion. |

Для добавления нового языка создайте `<language>.lproj/Localizable.strings`, зарегистрируйте вариант в `Localizable.strings` Xcode-проекта и добавьте проверку ключевых динамических сообщений в XCTest. Изменение системного языка macOS начинает действовать при следующем запуске AppTimer.
