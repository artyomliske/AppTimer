# Соответствие интерфейса AppTimer и GitHub-материалов

## Проверка — 18 августа 2026

Опубликованные до 2.1.0 в `README.md` изображения из `Docs/media/` были статичными демонстрационными иллюстрациями раннего визуального направления, а не автоматически снятыми скриншотами текущего приложения. Это подтверждалось preview Menu Bar с подписью «AppTimer 1.5» и preview Today без вкладки Timeline.

Актуальная сборка AppTimer 2.0.1 использует нативный SwiftUI `NavigationSplitView` с разделами «Сегодня», «Таймлайн», «Проекты», «Отчёты» и «Настройки». Поэтому установленное приложение закономерно отличается от GitHub-preview.

В 2.1.0 SwiftUI-интерфейс переработан под выбранный концепт, а устаревшие preview удалены из README. Публичная документация описывает только фактический нативный интерфейс и не использует концептуальную графику как скриншоты продукта.
