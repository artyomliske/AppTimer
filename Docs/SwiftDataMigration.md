# Миграции SwiftData

Начиная с архитектурной фазы 3, AppTimer открывает локальное хранилище с явным `AppTimerSchemaMigrationPlan`. Существующие модели `Project`, `WorkSession`, `SessionProjectAllocation` и `AppSegment` закреплены как снимок схемы в `AppTimerSchemaV1` и `AppTimerSchemaV2`.

| Версия схемы | Содержимое | Назначение |
|---|---|---|
| `1.0.0` | Текущая устойчивая схема AppTimer, включая необязательное поле `WorkSession.note` | Базовая совместимая модель для уже сохранённых локальных данных. |
| `2.0.0` | Тот же набор моделей и полей | Явная точка миграции, созданная до появления Timeline и новых типов моделей. |

Между V1 и V2 используется lightweight migration, поэтому данные не преобразуются и не удаляются. Перед добавлением Timeline следующая версия схемы должна быть отдельной `VersionedSchema`, а в плане должна появиться явная `MigrationStage`. Изменять существующие V1/V2 задним числом нельзя: это нарушит возможность открыть старое локальное хранилище.
